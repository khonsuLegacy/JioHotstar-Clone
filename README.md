## Key Features

- **Auto-Sliding Hero Banner:** Dynamic featured content showcase with smooth transitions.
- **Horizontal Movie Carousels:** Custom scrollable sliders with smooth gradient hover animations.
- **My Space Page:** Dedicated developer profile and user feedback section.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screens.

## Getting Started

1. **Clone the repository**
   ```bash
   git clone [https://github.com/khonsuLegacy/YOUR_REPO_NAME.git](https://github.com/khonsuLegacy/YOUR_REPO_NAME.git)
   ```
2. **Navigate to the project folder**
   ```bash
   cd YOUR_REPO_NAME
   ```
3. **Run the project**
   Open `index.html` directly in your browser or launch it using the Live Server extension in VS Code.
